Getting Started

1. Clone the repository

git clone https://github.com/nexmindsteamb-hash/MarketFlow-AI.git

2. Navigate to the frontend folder

cd MarketFlow-AI/frontend

3. Install dependencies

npm install

4. Start the development server

npm run dev
