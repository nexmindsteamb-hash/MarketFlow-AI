# MarketFlow AI - AI Module

Handles AI content generation (captions, hashtags, descriptions) using Google Gemini.

## Setup
1. Create an API key in Google AI Studio (aistudio.google.com).
2. In the `ai` folder, copy `.env.example` to `.env` and fill in `GEMINI_API_KEY` and `GEMINI_MODEL`.
3. Run `npm install`.

## Test
`node scripts/gemini-hello.js`
